# Kofi.Web

The shop's front end: a React SPA over `Kofi.API`. Customers browse, order and
pay at `/`; the administrator works at `/admin`.

Stack: Vite, React, TypeScript, TanStack Router (file-based routes in
`src/routes`), TanStack Query, an API client generated by Orval, shadcn/ui on
Tailwind CSS.

## Running

Aspire starts it with everything else:

```bash
dotnet run --project Kofi.AppHost
```

The shop is then at http://localhost:5173. Vite proxies `/api/*` to the API,
so the browser talks to one origin. The payment provider sends the customer
back to `/orders/{id}/payment-return` on that origin, which is a page of this
app.

The API needs the database and the payment provider that Aspire starts, so
run the shop through Aspire. `pnpm install && pnpm dev` here on its own is
enough when the API is already running on http://localhost:5276.

The logins are the ones in the solution README.

## The API client

`src/api/generated` is generated; don't edit it. After the API changes:

```bash
pnpm api:fetch   # snapshot the running API's OpenAPI document into openapi.json
pnpm api:gen     # regenerate the client from openapi.json
```

`src/api/fetcher.ts` adds the token, prefixes `/api` and turns a failed
response into one `ApiError` message.

## Smoke tests

With the shop running under Aspire:

```bash
pnpm exec playwright install chromium   # once
pnpm e2e
```

The tests create their own orders and products. Restarting Aspire gives a
fresh, freshly seeded database.
